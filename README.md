# Retail Inventory Risk Radar

Stockout early-warning system for a multi-store grocer (fictional "Harvest Lane Markets"), built end to end on Databricks:
Lakeflow ingestion → Unity Catalog governance → demand forecasting (MLflow) → transparent inventory-risk scoring → Lakebase operational serving → Genie natural-language Q&A → Databricks App for planners.
